# Fuzzy Logic Fundamentals

## Crisp Logic

True or False  
0 or 1  

Example:
Temperature > 37°C → Fever

---

## Fuzzy Logic

Truth has degrees.

Example:
37.8°C → Partially Fever (0.6)

Membership values range from 0 to 1.

---

## Fuzzy Set

Instead of:
x ∈ set (Yes/No)

We say:
x belongs with degree μ(x)

Example:

22°C might be:
Cold → 0.2
Comfortable → 0.7
Hot → 0.1

---

## Why This Matters

Real-world data is uncertain.
Fuzzy logic handles vagueness.
It mimics human reasoning.
