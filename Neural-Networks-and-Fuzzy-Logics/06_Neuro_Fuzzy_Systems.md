# Neuro-Fuzzy Systems

Combine:
- Neural learning
- Fuzzy reasoning

Goal:
Learn from data + remain explainable.

---

## How It Works

- Start with fuzzy rules
- Use neural training to tune membership functions
- Improve accuracy automatically

Example:
ANFIS (Adaptive Neuro-Fuzzy Inference System)

Used in:
- Time-series forecasting
- Fault detection
- Control systems
