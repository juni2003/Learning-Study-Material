## 🤖 AI, Agents, and Automation Roadmap

The next stage of this repository focuses on practical Artificial Intelligence,
Large Language Models, AI agents, and software automation.

The goal is to learn how AI systems are built and used inside reliable
software applications.

### Planned AI Topics

- Day 1 — AI Foundations and Prompt Engineering
- Day 2 — LLM APIs and Structured Outputs
- Day 3 — Retrieval-Augmented Generation
- Day 4 — Embeddings and Vector Search
- Day 5 — AI Agents and Tool Calling
- Day 6 — Multi-Agent Workflows
- Day 7 — Workflow Automation with Python
- Day 8 — AI Evaluation and Observability
- Day 9 — AI Safety, Guardrails, and Human Approval
- Day 10 — Deploying AI Applications

Each topic will include:

- A README file
- Theory and concepts
- A Python implementation
- A practical workflow example
- Common mistakes and best practices

The AI section follows the same learning style as the machine learning
sections in this repository: start with fundamentals, implement small examples,
and gradually build toward production-style systems.
